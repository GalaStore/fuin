# Roadmap

Fūin's roadmap lives on GitHub so it never goes stale here:

- **[Roadmap issue (pinned)](https://github.com/GalaStore/fuin/issues/1)** — what is planned, grouped by milestone, with progress.
- **[Milestones](https://github.com/GalaStore/fuin/milestones)** — `v0.2.0` (next release), `v0.3.0`, and `Backlog`
  (accepted but not scheduled).

Planned for `v0.2.0` (Linux only): Fūin as the system file chooser, so "Open" / "Save as" dialogs from other apps
use it — a picker mode plus an `org.freedesktop.impl.portal.FileChooser` backend (`OpenFile`, `SaveFile`,
`SaveFiles`) for xdg-desktop-portal ([#39](https://github.com/GalaStore/fuin/issues/39)).

Issues get on the roadmap after triage: they are labelled `status: on-roadmap` and given a milestone.
Have an idea? Open a [feature request](https://github.com/GalaStore/fuin/issues/new/choose).
